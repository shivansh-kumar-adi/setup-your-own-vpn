# Contributing

Thanks for helping improve this guide! Created and maintained by [Shivansh Kumar](https://shivanshonline.in).

## Ways to help
- Fix typos or unclear steps
- Add a guide (Android, iOS, OpenWrt, Docker, etc.)
- Improve diagrams
- Translate docs

## How to contribute
1. Fork the repository
2. Create a branch: `git checkout -b improve-linux-guide`
3. Make your changes and test every command on a fresh machine or VM
4. Commit: `git commit -m "Clarify NetworkManager steps"`
5. Push and open a Pull Request describing what and why

## Rules
- **Never** include real keys, IPs, or configs. Use placeholders like `<SERVER_PUBLIC_IP>`.
- Keep language beginner-friendly and explain *why*, not only *what*.
- Shell scripts must pass `bash -n` (and ideally `shellcheck`).
